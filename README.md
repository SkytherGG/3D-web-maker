# 3D-web-maker

Home of **🌍 3D World** — an agent skill that turns any brand into a
scroll-scrubbed, no-hard-cuts "fly through the world" landing page.

The skill lives in **[`3d-world/`](3d-world/)** — that folder is the unit you
install:

```bash
cp -R 3d-world ~/.claude/skills/    # Claude Code
cp -R 3d-world ~/.codex/skills/     # Codex
```

…or upload `3d-world/` to an Arena AI Agent Mode session.

- 📖 Skill instructions → [`3d-world/SKILL.md`](3d-world/SKILL.md)
- 📚 Full documentation → [`3d-world/README.md`](3d-world/README.md)
- 🎬 Working demo → `cd 3d-world/demo && python3 -m http.server 8000`
